# shorts_auto

台本テキストから、縦型(1080×1920)のショート動画を自動生成するツールです。

- 台本を空行区切りの段落に分け、各段落に合う背景映像を [Pexels](https://www.pexels.com/) から自動検索・ダウンロード
- 段落ごとに字幕を焼き込み
- 選んだネズミ画像を、動画の下部中央に最初から最後まで常時表示
- ナレーション音声は入っていません(別録り用に、字幕のタイムスタンプ一覧を書き出します)

ブラウザ上のフォーム(ネズミ画像を選ぶ → 台本を書く → ボタンを押す)から使えます。

## 必要なもの

- Python 3.10以上
- [Pexels API キー](https://www.pexels.com/api/)(無料で取得できます)

## セットアップ(Windows)

1. このリポジトリをダウンロード(またはクローン)する
2. `.env.example` を `.env` にコピーし、`PEXELS_API_KEY` に取得したキーを貼り付ける
3. `start_server.bat` をダブルクリックする
   - 初回は自動で仮想環境の作成・パッケージのインストールが行われます
   - しばらくするとブラウザで `http://127.0.0.1:5000` が自動的に開きます

`start_server.bat` を使わない場合は、手動で以下を実行してください。

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

## 使い方

1. ブラウザで開いた画面で、①ネズミ画像を1枚選ぶ
2. ②台本を書く(空行で段落を区切ってください)
3. ③「動画を作成」ボタンを押す
4. 生成が終わると、その場で動画がプレビュー再生され、ダウンロードもできます

生成には映像のダウンロード・書き出しがあるため、数十秒〜数分かかります。

### 台本の書き方

段落の先頭に以下のタグを付けると、背景映像の検索語や表示時間を個別に指定できます(省略可)。

```
[keyword: money, coins]
[duration: 4.5]
今日はお金についてお話しします。
```

- `keyword` を省略すると、本文中の日本語キーワードから自動で検索語を推定します
- `duration` を省略すると、文字数から自動で表示時間を計算します(既定: 6文字/秒、最短1.5秒)

## CLIから直接使う場合

フォームを使わず、コマンドラインから直接生成することもできます。

```bash
python main.py script_sample.txt output.mp4 --mouse-image "ネズミ画像/S__372113410.jpg"
```

## 設定(.env)

| 変数 | 説明 | 既定値 |
|---|---|---|
| `PEXELS_API_KEY` | Pexels APIキー(必須) | - |
| `FONT_PATH` | 字幕フォントのパス | `C:/Windows/Fonts/meiryo.ttc` |
| `OUTPUT_WIDTH` / `OUTPUT_HEIGHT` | 出力解像度 | 1080 / 1920 |
| `FPS` | フレームレート | 30 |
| `CHARS_PER_SECOND` | 字幕1文字あたりの表示速度 | 6 |
| `MIN_SEGMENT_DURATION` | 1段落の最短表示時間(秒) | 1.5 |

## ディレクトリ

- `ネズミ画像/` — 選択できるネズミ画像(5枚)
- `work/` — 背景映像のダウンロードキャッシュ(自動生成、Gitには含めない)
- `output/` — フォームから生成した動画の出力先(自動生成、Gitには含めない)
